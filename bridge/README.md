Run the bridge and web app here. Needs [Python](https://www.python.org/downloads/) 3.10 or newer.

First run:

`setup_and_start_bridge.bat`

Later runs:

`start_bridge.bat`

Then open http://127.0.0.1:5000 in your browser. Full steps: [setup guide, Option 2](../docs/setup.md#option-2--local-client-private--vpn-rooms).
